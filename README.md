A one-line roast of the noise-cancelling earbuds I wear every day: they promise silence, then turn my own chewing into a podcast I never subscribed to. The program writes that single original line (110 characters) to `entry.txt` for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes one line to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, falling back to `/output/entry.txt`).

## Entry

> My noise-cancelling earbuds promised silence, then turned my own chewing into a podcast I never subscribed to.
